WHAT YOU’RE LOOKING AT

A prediction test,
with real moving parts.

This project uses a released community reproduction of SuperMimic’s world model. The orange robot is its predicted state. The teal robot is the state computed by MuJoCo.

Same inputs

Both start together and receive the same motor commands. The comparison measures where their states diverge.

A script drives this experiment

The arm motion is a repeatable sine wave, not a trained policy. Zero command still tells the motors to hold their default joint targets.

No training in the browser

The model’s weights stay fixed. Adjusting a slider changes the test, not what the model has learned.

MuJoCo is also a model

Agreement with a simulator is useful evidence. It is not proof of what a physical robot will do.
