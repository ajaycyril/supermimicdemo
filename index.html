ABOUT THE COMPARISON

Two predictions.
One set of inputs.

The teal robot follows MuJoCo’s physics. The orange robot follows a learned dynamics model from CuboiLeo’s SuperMimic reproduction. Both receive the same motor commands and floor settings.

Scripted commands

A repeatable arm-motion script drives this experiment. It can fall. A trained controller would choose commands from observations.

A short error can become a large drift

A free rollout reuses each predicted state. Refreshing that state from MuJoCo shows the gap when both engines regularly start from the same state.

Adjust it while it runs

Motion, frequency, friction, noise and state refresh can change live. Every change is preserved in the recording.

What agreement tells us

MuJoCo is a numerical model too. Physical accuracy requires a measured trajectory from the real robot.
